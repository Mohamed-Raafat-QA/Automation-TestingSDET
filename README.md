## Automation projects

The seven projects implement the same 15 scenarios covering shipment tracking and checkout. Each mobile suite targets native Android and iOS apps. Open a project for setup instructions, smoke tests, and regression commands.

- [appium-java-mobile](appium-java-mobile/README.md)
- [appium-python-mobile](appium-python-mobile/README.md)
- [playwright-typescript-web](playwright-typescript-web/README.md)
- [robot-framework-mobile](robot-framework-mobile/README.md)
- [robot-framework-web](robot-framework-web/README.md)
- [selenium-java-web](selenium-java-web/README.md)
- [selenium-python-web](selenium-python-web/README.md)

Each project has its own GitHub Actions workflow. A change under a project runs its suite, and each workflow can also be started manually from the Actions tab.
